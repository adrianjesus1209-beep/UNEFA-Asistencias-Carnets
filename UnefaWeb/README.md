# Portal UNEFA estático

Sitio web estático construido con HTML y CSS. No requiere PHP, JavaScript, base de datos ni un servidor de aplicaciones.

## Abrir el sitio

Abre `index.html` en un navegador o sirve la carpeta del proyecto con cualquier servidor web estático. En XAMPP, coloca el proyecto dentro de `htdocs` y visita su URL local.

## Estructura

- `index.html`: página de inicio.
- `app/views/`: páginas HTML y fragmentos HTML organizados por sección.
- `public/css/`: estilos del sitio.
- `public/assets/`: imágenes, videos, plantillas y documentos descargables.
